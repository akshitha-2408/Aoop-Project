# Ride-Hailing Platform

## Overview
The Ride-Hailing Platform is a software application designed to connect passengers with nearby drivers for convenient transportation. It allows users to book rides, enables drivers to accept or reject requests, and manages the complete trip lifecycle from booking to completion.

This project is developed as part of the **Advanced Object-Oriented Programming (25CS2205E)** course.

## Key Features
- **User Management:** Passenger and driver registration and login.
- **Ride Booking:** Passengers can request rides by entering pickup and destination locations.
- **Driver Assignment:** Drivers can accept or reject ride requests.
- **Fare Calculation:** Calculates ride fares based on distance and applicable pricing rules.
- **Ride Tracking:** Manages ride status throughout its lifecycle.
- **Payment Management:** Records payment details and ride charges.
- **Ride History:** Maintains previous ride and booking information.
- **Cancellation Management:** Handles ride cancellations.

## User Roles
1. **Passenger:** Requests rides, views fare details, and manages bookings.
2. **Driver:** Receives ride requests, accepts or rejects them, and updates ride status.
3. **Administrator:** Manages users, drivers, and platform operations.
